# v0.9 — `path` repositories

Decided on 2026-09-16 ("go"), after 0.8.0. The opening cadrage is the
meta-analysis of v0.8 (`docs/plans/v0.8-dry-run-path.md`, §3 Part P),
which moved this out of 0.8: six sub-ports before the first green case.

## 1. Scope

### Problem

`{"type": "path", "url": "../lib"}` — monorepos (`packages/*`), a library
developed next to the project, a fork checked out locally — is the most
common repository type after `composer`. Today `vivacity update` refuses
it ("repository type "path" is not supported…") and `install` sends any
lock that carries a path package to the Composer fallback (`dist.type`
is not `zip`). A monorepo cannot use vivacity at all.

### Constraints

- Byte-identical `composer.lock`, `vendor/` (symlink target or mirrored
  content), `installed.json`/`installed.php` and stderr with Composer
  2.10.3 on Linux/macOS, proven by the harnesses; every ported file
  vendored under `docs/reference/` with its licence (Symfony
  Finder/Filesystem pieces are MIT: a NOTICE row).
- No new dependency without a DECISIONS entry (a glob crate is not
  needed: brace expansion + `*`/`?`/`[…]` matching is ~80 lines).
- Windows junctions are out of the parity claim: on Windows a path
  package goes through the fallback (scope issue), documented.

### Non-goals

- `vcs` repositories (v0.10).
- `options.reference: config`'s difference from `auto` beyond the git
  HEAD rule (identical otherwise), hg/fossil/svn guessers (git only, like
  the root guesser).
- The Windows junction strategy; `COMPOSER_MIRROR_PATH_REPOS` on Windows.
- `composer archive` and `archive.exclude` (the mirror uses
  `ArchivableFilesFinder($realUrl, [])`: no composer excludes).
- The `Symlink failed, fallback to use mirroring!` line: a symlink that
  fails on Linux/macOS is a filesystem error we surface, not a fallback
  (documented; Composer's fallback exists for exotic mounts).

### Success criteria (observable)

- P1 **lock**: on a new fixture `path-repos`, `harness/update.sh` writes
  the same lock as Composer (`composer.lock.expected` captured from
  Composer): path packages with `dist: {type: path, url: <glob match as
  written>, reference}` where reference = `sha1(json . serialize(options))`
  with `relative` auto-appended when absent, replaced by the HEAD hash
  when the package directory itself has a `.git` and `reference` is
  `auto`, null with `reference: none`; `transport-options` always
  carrying `relative` (and `symlink` when set); version precedence
  `options.versions[name]` > json `version` > `COMPOSER_ROOT_VERSION`
  (when `git rev-parse HEAD` agrees between the package dir and the cwd)
  > git guess (with the feature branch AND its parent as two packages)
  > `dev-main`; `~`/`$VAR` expansion; `GLOB_BRACE|GLOB_MARK|GLOB_ONLYDIR`
  semantics, sorted bytewise (`LC_ALL=C` in the harness); repo name
  `path repo (<url as written>)` in messages (an unsolvable case naming
  the repo is a `@stderr` case).
- P2 **install**: `harness/diff-vendor.sh path-repos` compares with
  `diff -r --no-dereference` plus an explicit `find -type l | readlink`
  inventory, in two passes: default (symlinks, relative through
  `findShortestPath(..., preferRelative: true)` when
  `transport-options.relative`, absolute otherwise) and
  `COMPOSER_MIRROR_PATH_REPOS=1` (mirror through the
  `ArchivableFilesFinder` rules: VCS directories at any depth,
  root `.gitattributes export-ignore`/`-export-ignore` (two-field lines
  only, pattern matched at any depth), symlinks pointing outside the
  source or dangling dropped, empty directories kept, links inside
  recreated with their raw target when they point to a file or an empty
  directory and **dropped when they point to a non-empty directory**
  (`accept()` follows `isDir()`, the Finder does not follow links).
  `options.symlink: false` mirrored; `symlink: true` symlinked.
  `installed.json`/`installed.php` identical (`install-path` is the
  vendor path, `reference` the dist reference). A second `install` is a
  no-op; a changed `reference` (json edited) prints `  - Upgrading
  acme/x (dev-main abc1234 => dev-main def5678): Source already present`
  on a symlinked package (`FileDownloader::update` prints the appendix
  computed on the *current* vendor path, whose realpath is the source)
  and re-mirrors a mirrored one; `remove` of a path package unlinks the
  symlink (never the target) or removes the mirror. The Composer line
  `  - Installing acme/x (dev-main abcdef1): Symlinking from
  ../packages/x` / `Mirroring from …` is printed. The inventory diffs
  **modes and link targets** (`stat` per entry, both sides): a mirrored
  file gets `0666 & ~umask` plus the source's executable bits and the
  source mtime (Symfony `Filesystem::copy`), directories `0777 & ~umask`;
  the mirror pass runs without `--exclude=.git` so the VCS exclusion is
  actually observed.
- P3 **messages**: `Locking acme/x (dev-feature-x 3f2a1b0)` (dev package
  without source: dist reference, 7 chars), `(dev-main)` with `reference:
  none`; `install` refuses "Package %s cannot install to "%s" inside its
  source at "%s"" like `PathDownloader::download`.
- P4 **harness plumbing**: the fixture's nested git repositories are
  built by `fixtures/make.sh` deterministically (`init.defaultBranch`,
  author/date/committer pinned, `commit.gpgsign=false`, `core.autocrlf`
  off) so the HEAD hashes are stable; `steps.sh`/`update.sh` copy the
  whole fixture tree and git-init the project like `diff-vendor.sh`
  does; every harness sets `GIT_CEILING_DIRECTORIES` to the **parent**
  of the project directory (git never looks at the ceiling directory
  itself: the project's own `.git` must stay visible from `packages/*`,
  the checkout's must not) and `GIT_CONFIG_GLOBAL=/dev/null
  GIT_CONFIG_NOSYSTEM=1`; the project is committed on a non-feature
  branch other than `main` (`develop`) so a guess through the project's
  repository is distinguishable from the `dev-main` fallback;
  `diff-vendor.sh` excludes `path-repos` from the Windows default list.

## 2. Plan

Reference to vendor (`docs/reference/` + drift map): `PathRepository.php`,
`PathDownloader.php`, `Package/Version/VersionGuesser.php` (already for
the root? check: `root_version.rs` was ported from it — vendor it),
`Package/Archiver/{ArchivableFilesFinder,ArchivableFilesFilter,BaseExcludeFilter,GitExcludeFilter}.php`,
`Util/Platform.php` (`expandPath`), `Util/Filesystem.php` (already),
Symfony `Finder/Glob.php` (`toRegex`) and `Filesystem::mirror` excerpt
with the Symfony MIT licence.

1. **`vivacity-core::phpserialize`** — `serialize()` of the JSON-decoded
   `options` object only: assoc arrays with insertion order, `i:`,
   `s:len:""`, `b:`, `N;`, and `d:` for JSON floats via the shortest
   round-trip (`serialize_precision = -1`; exponent form left as an
   error rather than guessed). Order matters for the hash: `relative` is
   appended **last** only when absent, and a `"relative": null` written
   by the user is replaced in place (`isset` false, key kept). Unit
   oracle against PHP through the phar (`php -r 'echo
   serialize(json_decode(…, true));'`).
2. **`vivacity-core::glob`** — brace expansion (nested, `GLOB_BRACE`),
   `*`/`?`/`[…]` per path segment (a leading `.` is never matched by a
   metacharacter: no `GLOB_PERIOD`), `GLOB_ONLYDIR`, `GLOB_MARK`
   (trailing `/` then stripped like `getUrlMatches`), bytewise sort; the
   "url does not exist" rule exactly as written: only `[*{}]` count as
   metacharacters for the `dirname` walk (`packages/?` without a match
   is the error even when `packages/` exists). Unit-tested against PHP
   `glob()` on a temp tree with dot-directories, `?` and `[`.
3. **`root_version.rs` → a git-like guesser**: `guess_git_in(dir)` with
   no `.git` precondition and no `GIT_DIR`/`GIT_WORK_TREE` pin (git walks
   up; `GitUtil::cleanEnv` only), returning `{version, pretty,
   feature_version, feature_pretty, commit}` after `postprocess`; the
   root path keeps its current behaviour through the same function.
   `is_feature_branch` reads the package's own `non-feature-branches`.
4. **`vivacity-resolver::path_repo`** — `Repository::Path`: `expandPath`
   (`~/`, `$VAR`/`%VAR%`, `HOME` on Windows), `relative` default,
   `getUrlMatches`, per match: read composer.json, build the package
   config exactly like `initialize()` (dist, reference rule, transport
   options, version precedence, feature + parent packages), load through
   `loader::load` with `Origin::Repository(i)`, members in the arena;
   `array_repository_load_packages` for lookups; `getRepoName`.
   `open_repository` accepts `path`; `RepoError` texts of the reference.
5. **Lock**: `lockfile.rs` — verify the dump of a path package (`dist`
   without `shasum`, `transport-options`, no `source`, no `time`) by the
   oracle; fix what differs.
6. **Scope** (`vivacity-core::scope`): a lock package with `dist.type ==
   "path"` is native on Linux/macOS when `dist.url` (relative to the
   project) resolves to a directory, `NoUsableDist` otherwise; on
   Windows always `NoUsableDist` (fallback).
7. **Installer** — `PathDownloader` port in `vivacity-core::path_install`:
   strategy from `transport-options.symlink` + `COMPOSER_MIRROR_PATH_REPOS`
   (`(bool)` semantics), the "inside its source" refusal, removal of the
   existing path, symlink (relative via `findShortestPath` gaining the
   `preferRelative` parameter, on `realpath(vendor)/<name>` normalized
   lexically — the leaf no longer exists after `removeDirectory`;
   trailing `/` on the target like `symlink($shortestPath.'/', $path)`)
   or mirror
   (`ArchivableFilesFinder`: Symfony Finder `sortByName`, `ignoreVCS`
   names, `ignoreDotFiles(false)`, the filter with `GitExcludeFilter`
   patterns via `Glob::toRegex` (port), outward and dangling links
   dropped (`getRealPath()` false), the relative path handed to the
   filters is the realpath's, `accept()` = non-dirs and empty dirs with
   `isDir()` following links; `mirror`: links re-created with the raw
   target, dirs `0777 & ~umask`, files copied to `0666 & ~umask | (src &
   0o111)` with the source mtime); the store is bypassed (identity =
   version + dist reference for the no-op decision, as today); `.git`
   means a **directory** both for the HEAD reference (`is_dir`) and the
   mirror exclusion (a `.git` file of a worktree is copied); the
   operation line with its `: Symlinking from …` / `: Mirroring from …`
   / `: Source already present` appendix computed like
   `getInstallOperationAppendix` on the current vendor path;
   `update` = appendix line, remove, silent install (the `Upgrading`
   line on a symlinked package says `Source already present`); `remove`:
   `symlink_metadata` first (a dangling link is unlinked, never
   `remove_dir_all`), the "source is still present" case; a zip→path or
   path→zip transition goes through the same update path.
8. **Fixture `path-repos`** (`fixtures/projects/path-repos` +
   `fixtures/make.sh` step): root `composer.json` with
   `repositories: [{type: path, url: "packages/*"}, {type: path, url:
   "libs/{alpha,beta}", options: {symlink: false, versions: {"acme/beta":
   "2.0.0"}}}, {type: path, url: "vendor-src/gamma", options:
   {reference: none}}]`, packages: `acme/alpha` (json `version`),
   `acme/beta` (`options.versions`), `acme/gamma` (nested git repo on
   `feature-x` off `main` → two packages, HEAD reference), `acme/delta`
   (no version, no git of its own → guessed from the project's repo the
   harness commits → `dev-main`; and `COMPOSER_ROOT_VERSION` case),
   `acme/epsilon` with `.gitattributes export-ignore` (plus a three-field
   line that must be ignored) and a nested `.git` directory to be
   excluded by the mirror, an empty directory, a `0600` and a `0755`
   file, and four links: to an inner file, to an inner empty directory,
   to an inner non-empty directory (dropped), dangling. Requires between
   them (`acme/alpha` requires `acme/beta ^2`). The manifest sets
   `"packagist.org": false` (otherwise any name missing from the path
   repositories reaches the network) and the fixture ships an empty
   snapshot tarball so the harness plumbing is unchanged (`steps.sh`
   already passes `--no-audit` to `update`/`require`/`remove`; `install`
   only audits on `--audit`).
9. **Harnesses**: `update.sh` (lock identical + expected), `steps.sh`
   cases (`require acme/gamma`, `update acme/gamma`, `remove acme/alpha`,
   `--dry-run` variants, `@env:COMPOSER_MIRROR_PATH_REPOS=1`,
   `@env:COMPOSER_ROOT_VERSION=1.2.3`, json of a symlinked package
   edited then `install` (`Source already present`) and the mirrored
   twin, a stale lock on a symlinked package **not** targeted by
   `update acme/gamma` (Composer unlocks symlinked path packages in
   `PoolBuilder`, ported in `pool.rs` but never exercised) and its
   `symlink: false` twin that stays locked), `diff-vendor.sh path-repos`
   in both strategies with `--no-dereference` + a `stat` inventory
   (modes, link targets) and no `--exclude=.git` on the vendor scope,
   `transitions.sh` zip→path and path→zip, `removal.sh` case,
   `GIT_CEILING_DIRECTORIES` (parent), `GIT_CONFIG_GLOBAL`, `LC_ALL=C`.
10. Docs: README ("Repositories: `composer` and `path`"), HANDOVER
    (Windows fallback, hg/svn not guessed, the symlink-failure fallback
    line), DECISIONS (glob and serialize hand-written; Windows choice),
    NOTICE (Symfony), CHANGELOG, CONTRIBUTING (next: `vcs`).

### Order

8 (fixture + Composer captures: lock, `stat` inventories in both
strategies, stderr of every planned step — read before any Rust) → 1 →
2 → 3 (unit oracles against PHP only for what the fixture cannot
discriminate) → 4 + 5 (lock green on `update.sh`) → 6 + 7 + 9 (install
green) → 10. Meta-analysis done (§3); independent review of 3, 4 and 7
before merge. Version 0.9.0; tag on the user's word.

## 3. Meta-analysis

Run on 2026-09-16 by a fresh subagent (cadrage + plan only, PHP source
and the Rust tree read-only). Thirteen findings; the four major ones
were each re-checked in the reference before amending the plan above.
