# v0.6 — rename to vivacity, GPL removal, English docs

Decided on 2026-09-14 after the 0.5.0 release.

## Why

- **Name.** `svandragt/vivace` (created 2026-09-06, four days before this
  repository) is a Rust reimplementation of Composer with the same
  byte-identical promise, binary `viv`, v0.11.0 as of today. Same name,
  same pitch, same week: confusing for everyone and his precedence is a
  fact. The name is renamed to **vivacity** — free on crates.io (all four
  crates), no Rust project of that name on GitHub.
- **License.** `crates/vivace-core/src/scaffold.rs` is a declared port of
  `drupal/core-composer-scaffold`, which is GPL-2.0-or-later; the templates
  in `assets/scaffold/` are copied from it. A port is a derivative work,
  incompatible with distributing the crate and the binaries under
  MIT/Apache-2.0. The emulation is removed; Drupal projects using the
  scaffold go through the existing `composer install` fallback, which the
  Drupal fixture keeps proving correct.
- **Docs.** Module and item docs, inline comments and `--help` texts were in
  French; docs.rs and `--help` are now English.

## Order

1. Land the English docs (four crates, translated in parallel, one commit).
2. Remove the GPL port: `scaffold.rs`, `assets/scaffold/`,
   `assets/scaffold-fingerprints.json`, `docs/reference/drupal-scaffold/`,
   `tests/oracle_scaffold.rs`, the `scaffold` fields of `ScopeReport` and
   `InstallPlan`, the pre-dump hook in the CLI; `drupal/core-composer-scaffold`
   becomes an unsupported plugin (fallback). `harness/transitions.sh`
   becomes "scaffold present → Composer"; `harness/diff-vendor.sh drupal`
   still passes (through the fallback). NOTICE/README/HANDOVER/DECISIONS
   updated; CHANGELOG says why.
3. Rename: crate names (`vivacity`, `vivacity-core`, `vivacity-resolver`,
   `vivacity-autoload`), binary `vivacity`, library entry `vivacity::run`,
   env vars `VIVACITY_*` (`VIVACE_*` no longer read), cache/store
   directories under `vivacity`, install.sh, action.yml, workflows (asset
   names), harnesses, tools, docs, fixture notices. Historical plans under
   `docs/plans/` keep their text. GitHub repository renamed (redirects
   kept). Version 0.6.0 (the library entry point changes name).
4. Release: tag `v0.6.0` on green CI (release guard updated for the new
   names), `cargo publish --workspace` under the new names, `cargo yank`
   of `vivace*` 0.5.0 with the rename in their crates.io description.
5. Tell luthermonson (draft shown first).

## Not in scope

Feature work. The Drupal fixture, `composer/installers` emulation (MIT)
and the `drupal/core-project-message` / `core-recipe-unpack` "benign
plugin" handling (they are installed as plain libraries, nothing is
ported from them) stay.
