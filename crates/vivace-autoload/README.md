# vivace-autoload

Composer's autoloader generation (`AutoloadGenerator`, `ClassMapGenerator`, PSR-0/PSR-4, files, exclusions, optimized and authoritative modes) ported for [vivace](https://github.com/Adelagric/vivace); the generated vendor/composer/*.php files are byte-identical to Composer 2.10.3's, checked against the phar on the repository's fixtures.
