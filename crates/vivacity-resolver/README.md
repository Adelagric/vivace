# vivacity-resolver

Composer 2.10.3's dependency resolution ported function by function for [vivacity](https://github.com/Adelagric/vivacity): composer/semver, Packagist v2 metadata with Composer's cache layout, `path` repositories (`PathRepository`: globs, `sha1(json . serialize(options))` or git HEAD references, the git version guess), pool builder and optimizer, rule set, the CDCL solver, the default policy, the lock transaction and lock writer, JsonManipulator and VersionSelector for require/remove, the pool policies (security advisories, malware lists, abandoned packages), and Composer's explanations of an unsolvable set (`Problem`, `Rule::getPrettyString`, `SolverProblemsException`). Checked against Composer on frozen Packagist snapshots (same candidate pool, same solver decisions, same lock, same messages byte for byte).
